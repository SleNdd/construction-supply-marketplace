# Браузерные испытания

Playwright запускает Chromium и проверяет приложение через интерфейс. Для испытаний используются отдельная база с учебными данными и свои процессы API и Next.js. Разделение с рабочим демо обеспечивается отдельными портами, процессами и базой. Рабочее демо на порту 3000 для этого не подходит: сценарии создают объекты и заказы, отменяют неоплаченный заказ и завершают учебную поставку.

## Локальный запуск на Windows

Нужны Node.js 22, npm и работающий Docker. Команды выполняются из каталога проекта. В первом терминале подготовьте временную PostgreSQL:

```powershell
docker run --name obektmarket-browser-test --rm -d -p 127.0.0.1:5435:5432 -e POSTGRES_DB=obektmarket_test -e POSTGRES_USER=obektmarket -e POSTGRES_PASSWORD=browser-test-password postgres:17-alpine
for ($attempt=0; $attempt -lt 30; $attempt++) {
  docker exec obektmarket-browser-test pg_isready -U obektmarket -d obektmarket_test > $null
  if ($LASTEXITCODE -eq 0) { break }
  Start-Sleep -Milliseconds 500
}
if ($LASTEXITCODE -ne 0) { throw 'PostgreSQL не готова к подключению' }
cd api
$env:DATABASE_URL='postgres://obektmarket:browser-test-password@localhost:5435/obektmarket_test'
$env:DEMO_SEED='true'
$env:API_PORT='4100'
$env:CORS_ORIGIN='http://localhost:3100'
$env:COOKIE_SECURE='false'
$env:DADATA_API_KEY=''
$env:GIS_ROUTING_KEY=''
npm ci
npm run migrate
npm run seed
npm run build
npm run start:prod
```

Дождитесь сообщения о запуске API. Если миграция, загрузка данных или сборка завершились с ошибкой, исправьте её до продолжения.

Во втором терминале из каталога проекта:

```powershell
cd web
$env:API_INTERNAL_URL='http://localhost:4100'
$env:PUBLIC_ORIGIN='http://localhost:3100'
npm ci
npx playwright install chromium
npm run build
npm run test:e2e
```

Тестовый сервер Next.js на порту 3100 запускается и останавливается конфигурацией Playwright. Браузерные сессии отдельных тестов не делят cookies и локальную корзину. Реальные сценарии используют подготовленный API, а тесты гонок ответов подменяют только необходимые HTTP-ответы. Такая подмена проверяет поведение интерфейса и не подтверждает работу внешнего сервиса.

После испытания остановите API сочетанием Ctrl+C и выполните:

```powershell
docker stop obektmarket-browser-test
```

У этого контейнера нет постоянного тома, поэтому его тестовая база будет удалена вместе с контейнером. Данные основного Compose-стенда сохраняются.

## Что проверяет набор

Сценарии с настоящим локальным API проверяют каталог, объект, фасовку, импорт, закупку по этапам, резерв и отмену заказа, поставку, действия поставщика и администратора, а также сохранение точки доставки. Данные создаются только в отдельной тестовой базе.

Подготовленные ответы используются для проверки задержек и ошибок расчёта, адресных подсказок и маршрута, повреждённого хранилища и граничного ввода. Они испытывают клиентскую обработку; работу действующих DaData/2ГИС эти проверки не подтверждают. Чистые проверки отдельно испытывают парсер импорта и денежный форматтер.

Карта проверяется при смене поставки, рейса и склада, с запоздавшим ответом, повреждённой геометрией и отсутствующими координатами. В оформлении проверяются восстановление прежнего тела и ключа заказа, принадлежность объекта и блокировка формы до завершения восстановления.

Адаптивность проверяется на телефоне и широком экране: горизонтальное переполнение, размеры действий, две темы, фокус мобильной панели и reduced motion. Это проверки заданных экранов и состояний, а не полный аудит доступности или всех браузеров.

Результаты конкретного прогона приведены в [отчёте](TEST_RESULTS.md). Для просмотра локального отчёта выполните `npx playwright show-report` из `web`. При отказе сохраняются трасса и снимок. Каталоги `playwright-report` и `test-results` исключены из Git и Docker-контекста.

GitHub Actions готовит собственную PostgreSQL 17, применяет миграции, загружает данные, собирает API и интерфейс, затем запускает тот же набор. Отчёт хранится в артефакте `browser-test-report` семь дней. Проверки не выполняют банковскую оплату и не обращаются к действующим внешним сервисам.
