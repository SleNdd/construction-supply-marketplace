# Фотографии в каталоге

Карточки показывают фотографии категорий материалов, а не конкретных товаров поставщиков. Для сайта взяты уменьшенные до 1200 пикселей копии файлов Wikimedia Commons. В интерфейсе фотографии обрезаются по размеру карточки; исходные изображения здесь не ретушировались. Лицензии фотографий действуют отдельно от лицензии программного кода.
