# Пояснительная записка

`Пояснительная_записка_ОбъектМаркет.docx` — редактируемый текст ВКР. Титульный лист содержит незаполненные реквизиты руководителя и кафедры; их вносят по утверждённому бланку.

Исходный текст находится в `content.md`. Для пересборки требуется Python 3 с `python-docx`: `python build.py`. Для отдельного кандидата можно указать `python build.py --output путь.docx`. Рисунки берутся из `figures/` и `../screenshots/`; даты снимков указаны в тексте. Скрипт `figures/build.py` пересоздаёт схемы на Windows с Pillow и системным Arial.

На Windows с установленным Microsoft Word после пересборки выполните `powershell -File finish.ps1`: скрипт обновит содержание и номера страниц. Перед сдачей сверьте документ с действующей методичкой кафедры и внесите данные руководителя.

Версия от 2 октября содержит пять рисунков и девять таблиц. Документ открыт в Microsoft Word, поля обновлены; экспортированные 69 страниц просмотрены после исправления переносов. Это проверка вёрстки рабочей версии. Формальный шаблон, реквизиты и сравнительное испытание закупки ещё требуют завершения.

Тема: «Разработка информационной системы выбора и поставки строительных материалов с учётом потребностей строительного объекта».
