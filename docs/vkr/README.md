# Пояснительная записка

`Пояснительная_записка_ОбъектМаркет.docx` — редактируемый текст ВКР. Титульный лист содержит незаполненные реквизиты руководителя и кафедры; их вносят по утверждённому бланку.

Исходный текст находится в `content.md`. Для пересборки требуется Python 3 с `python-docx`: `python build.py`. На Windows с установленным Microsoft Word после пересборки выполните `powershell -File finish.ps1`: скрипт обновит содержание и номера страниц. Перед сдачей сверьте документ с действующей методичкой кафедры и внесите данные руководителя.

Тема: «Разработка информационной системы выбора и поставки строительных материалов с учётом потребностей строительного объекта».
