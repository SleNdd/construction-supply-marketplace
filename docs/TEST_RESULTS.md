# Результаты локальной проверки

Проверка проведена 27–28 сентября 2026 года на рабочем состоянии проекта перед выпуском. Исходный стенд: Windows, Docker Desktop 29.2.1, контейнеры PostgreSQL 17, API и веб-приложения из `docker-compose.yml`. Для интеграционного теста использована отдельная PostgreSQL 16 с базой `obektmarket_test`. Внешние ключи 2ГИС и DaData не задавались.

| Проверка | Команда или способ | Результат |
| --- | --- | --- |
| Модульные проверки API | `cd api && npm test` | 12 из 12 пройдены: хеширование пароля, округление калькуляторов, повторы предложения, доставка по поставщикам, учебная зона адреса и семь групп проверок внешних сервисов. |
| Интеграционная проверка API | `cd api && npm run test:integration` при `TEST_DATABASE_URL` отдельной базы | Пройдены обязательный ключ запроса, повтор и конфликт, отмена и истечение резерва, права доступа, одновременная покупка последнего остатка. В последнем случае один заказ был принят, второй отклонён без отрицательного остатка. Дополнительно проверены отсутствие общей блокировки входа для 40 неверных адресов, неизменность единицы измерения после правки карточки, изменение и удаление позиции объекта с проверкой владельца, а также завершение двух поставок одного заказа при параллельных запросах. |

Ошибка слишком длинного адреса показана с кнопкой повторного расчёта. Новый заказ в этой проверке не создавался; искусственные задержки сети не вводились. |

В корзине до расчёта доставки оформление обозначено неактивной кнопкой. Полный аудит WCAG и всех окон не проводился. |

Параллельный тест проверяет конкретное выполнение. Все варианты чередования транзакций тест не перебирает; порядок блокировки общего заказа перед поставкой задан в обработчике событий.

Тестовые заказы добавляются в локальную демонстрационную базу. Они не являются данными действующей компании. Платёж меняет только учебный статус, а маршрут на карте без ключа является схемой. Работа с действующими ключами и отказами реальных 2ГИС/DaData в этом запуске не испытывалась. Испытание с участниками и замер времени ручной закупки не проводились; выводов об экономии времени или денег по этим проверкам нет.
