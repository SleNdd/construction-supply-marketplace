# Результаты локальной проверки

Проверка проведена 27–28 сентября 2026 года на рабочем состоянии проекта перед выпуском. Исходный стенд: Windows, Docker Desktop 29.2.1, контейнеры PostgreSQL 17, API и веб-приложения из `docker-compose.yml`. Для интеграционного теста использована отдельная PostgreSQL 16 с базой `obektmarket_test`. Внешние ключи 2ГИС и DaData не задавались.

| Проверка | Команда или способ | Результат |
| --- | --- | --- |
| Модульные проверки API | `cd api && npm test` | 5 из 5 пройдены: хеширование пароля, округление калькуляторов, повторы предложения, доставка по поставщикам и учебная зона адреса. |
| Интеграционная проверка API | `cd api && npm run test:integration` при `TEST_DATABASE_URL` отдельной базы | Пройдены обязательный ключ запроса, повтор и конфликт, отмена и истечение резерва, права доступа, одновременная покупка последнего остатка. В последнем случае один заказ был принят, второй отклонён без отрицательного остатка. Дополнительно проверены отсутствие общей блокировки входа для 40 неверных адресов, неизменность единицы измерения после правки карточки, изменение и удаление позиции объекта с проверкой владельца, а также завершение двух поставок одного заказа при параллельных запросах. |
| Сквозной API-сценарий | `cd api && npm run smoke` | Пройден путь от каталога и расчёта до заказа, учебной оплаты, назначения водителя и статуса «доставлен»; проверены отказ в чужом действии и защита изменения состояния от запроса с другого источника. |
| Сборка и статический анализ | `cd api && npm run build`; в `web`: `npm run lint`, `npm run typecheck`, `npm run build` | Все команды завершились успешно. |
| Запуск в контейнерах | `docker compose up --build -d`; `docker compose ps` | PostgreSQL и API получили статус `healthy`, веб-приложение открылось на `http://localhost:3000`. Миграции и загрузка учебных записей прошли при первом запуске. |
| Браузерный путь покупателя | Microsoft Edge через Playwright, локальный Docker-стенд | Вход, объект «Ремонт жилого дома», план закупки, корзина, расчёт доставки, заказ и отмена прошли без ошибок страницы. Для 12 мешков цемента показано: материалы 5 040 ₽, доставка 650 ₽, итог 5 690 ₽. |
| Браузерный путь поставки | Microsoft Edge через Playwright, локальный Docker-стенд | Покупатель создал и оплатил учебный заказ, диспетчер назначил водителя, водитель последовательно отметил загрузку, рейс и доставку. Ошибок страницы не зафиксировано. |
| Работа с объектом и импортом | Microsoft Edge через Playwright, локальный Docker-стенд | Проверены число позиций в списке и карточке, изменение количества с возвратом исходного значения, удаление добавленной позиции, CSV с корректной и ошибочной строками, вывод ошибки и запрет повторной отправки успешной строки. После добавления плана checkout выбрал объект; после изменения количества в корзине автоматическая привязка исчезла. |
| Ведомость XLSX | Microsoft Edge через Playwright, локальный Docker-стенд | Файл с датой этапа прочитан, строка добавлена в объект и затем удалена. Исходное число позиций восстановлено. |
| Справочники администратора | Microsoft Edge через Playwright, локальный Docker-стенд | Созданы тестовые категория и товар, товар найден и изменён через интерфейс. При ширине 390 px горизонтального переполнения нет. Тестовые записи после проверки удалены из локальной базы. Интеграционный тест отдельно проверил идентификатор категории в каталоге и очистку описания товара администратором. |
| Сортировка каталога | Запросы API, интеграционный тест и Chromium на локальном стенде, 28 сентября | Для 11 демотоваров API вернул цены по возрастанию от 420 до 2 150 ₽ и по убыванию от 2 150 до 420 ₽. Тест также проверил одинаковый набор товаров и размещение товара без предложения в конце обеих сортировок. В браузере карточки показаны в нужном порядке; после смены направления клавиатурой фокус остался на выборе сортировки. |
| Адаптивность | Скриншоты страниц при ширине 1440, 768 и 390 px; браузерная проверка объекта и кабинета администратора при 390 px | Главная, каталог, объект и кабинет администратора открылись без горизонтального переполнения страницы. Проверены основные элементы навигации, карточки, фильтры и переключатель темы в мобильном меню. Проверка всех экранов с клавиатуры и аудит WCAG отдельно не проводились. |
| Клавиатурное управление | Chromium на локальном Docker-стенде, узкий и обычный экран | Проверены переход к содержимому, начальный фокус окна создания объекта, переход по Shift+Tab внутри окна, Escape и возврат фокуса. После входа фокус переходит к ссылке кабинета. После удаления временной позиции объекта фокус переходит к содержимому, а список возвращается к одной исходной позиции. Выбор CSV/XLSX определяется как кнопка. При ширине 390 px фильтры получают фокус, закрываются Escape, а после выбора категории фокус возвращается к кнопке фильтров. В корзине до расчёта доставки оформление обозначено неактивной кнопкой. Полный аудит WCAG и всех окон не проводился. |

Параллельный тест проверяет конкретное выполнение. Все варианты чередования транзакций тест не перебирает; порядок блокировки общего заказа перед поставкой задан в обработчике событий.

Тестовые заказы добавляются в локальную демонстрационную базу. Они не являются данными действующей компании. Платёж меняет только учебный статус, а маршрут на карте без ключа является схемой. Работа с действующими ключами и отказами реальных 2ГИС/DaData в этом запуске не испытывалась. Испытание с участниками и замер времени ручной закупки не проводились; выводов об экономии времени или денег по этим проверкам нет.
