# API «ОбъектМаркет»

NestJS + PostgreSQL. Контракт приведён в [`openapi.yaml`](openapi.yaml); интерактивная версия доступна по `/api/docs`.

## Локальный запуск

Создайте базу PostgreSQL, заполните `.env` по `.env.example` и выполните:

```bash
npm ci
npm run migrate
npm run seed # только при DEMO_SEED=true
npm run build
npm run start:prod
```

Миграции выполняются по имени файла и повторно не применяются. `npm run seed` разрешён только при явном `DEMO_SEED=true` и добавляет отсутствующие демонстрационные записи: существующие пользователи, остатки и заказы не сбрасываются. После загрузки доступны учётные записи `buyer@example.test`, `supplier@example.test`, `supplier2@example.test`, `dispatcher@example.test`, `driver@example.test`, `admin@example.test`; пароль каждой — `Demo2026!`. Эти учётные записи предназначены только для локального учебного стенда. В обычном развёртывании демоданные не загружают: первого администратора создают командой `npm run bootstrap:admin` с переменными `ADMIN_NAME`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` (уникальный пароль не короче 12 символов). Повторный запуск для того же адреса не меняет существующий аккаунт и сообщает об ошибке.

## Проверка

`npm test` проверяет расчёты, хеширование паролей и группировку позиций. После запуска API с PostgreSQL `npm run smoke` проходит каталог, расчёт, оформление заказа, повтор с `Idempotency-Key`, учебную оплату и рейс. Для другого адреса API задайте `API_BASE_URL`. Неоплаченный заказ резервирует остатки на 30 минут. Покупатель может отменить его через `POST /orders/:id/cancel`; истёкшие резервы освобождаются транзакционно при запросах расчёта и заказа. Для демонстрационной доставки адрес должен начинаться с «Астрахань, » или «г. Астрахань, »; ответ расчёта содержит `zoneAvailable`.

## Безопасность и деморежим

Сеанс хранится в HttpOnly cookie, а его случайный токен — только как SHA-256 хеш в базе. Для HTTPS выставьте `COOKIE_SECURE=true`, задайте точный `CORS_ORIGIN`, настройте TLS на обратном прокси и не публикуйте демонстрационные пароли. Изменяющие запросы с чужим `Origin` или `Sec-Fetch-Site: cross-site` отклоняются; это предполагает один доверенный веб-источник. Вход ограничен по адресу почты и IP на 15 минут. API не хранит платёжные реквизиты и не снимает деньги.

Без ключей DaData/2ГИС сервер возвращает локальные подсказки и схематический маршрут с `source: demo`. При настроенном ключе ошибка внешнего сервиса возвращает `502`, а не выдаёт демоданные за реальный результат. Ключ `GIS_MAP_KEY` публичен по природе браузерного MapGL и должен быть ограничен по домену в панели 2ГИС. `DADATA_API_KEY` и `GIS_ROUTING_KEY` передаются только серверу.
