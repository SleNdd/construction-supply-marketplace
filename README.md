# ОбъектМаркет

Информационная система для выбора строительных материалов, комплектации объекта и планирования поставок. Репозиторий находится в разработке.

Проект включает торговую витрину для частного покупателя и рабочие сценарии заказчика, поставщика, диспетчера и водителя. Денежные операции и движение транспорта в учебной версии моделируются без реальных платежей и GPS. Подробная постановка задачи и правила демо находятся в [описании проекта](docs/PROJECT.md).

## Структура

- `web/` — интерфейс на Next.js и TypeScript.
- `api/` — NestJS API на TypeScript и миграции PostgreSQL.
- `docs/` — архитектура, пользовательские инструкции и материалы защиты.
