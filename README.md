# ОбъектМаркет

«ОбъектМаркет» — функциональный прототип информационной системы снабжения строительного объекта. Снабженец или прораб переносит ведомость материалов, рассчитывает количество упаковок, сравнивает предложения поставщиков и оформляет закупку к выбранному этапу работ. Обычная покупка из каталога также доступна. Поставщик управляет ценой и остатками, диспетчер назначает рейс, водитель отмечает этапы доставки.

Товары, организации и заказы учебного набора вымышлены. Подтверждение оплаты меняет статус заказа; деньги не списываются. Статусы рейса водитель отмечает вручную. Карта связывает сохранённые склады поставки с выбранной точкой доставки; движения автомобиля и GPS нет.

## Запуск

Нужен Docker с Compose. На свободном порту 3000 выполните:

```bash
cp .env.example .env
docker compose up --build -d
```

На Windows скопируйте файл `.env.example` в `.env` любым удобным способом. Перед запуском задайте свой `POSTGRES_PASSWORD` в `.env`. Сайт будет доступен по адресу [localhost:3000](http://localhost:3000). Описание методов находится в [OpenAPI](api/openapi.yaml). Первый запуск применяет миграции и загружает демоданные. Даты этапов учебного объекта назначаются на 30 и 60 дней после первой загрузки; при повторном запуске уже созданный объект не меняется. Для просмотра журналов: `docker compose logs --tail=100 api web db`.

Ключи 2ГИС и DaData не обязательны. Без них работают локальные подсказки адресов и подписанная схема между выбранными точками, без дорожного расстояния и времени. При оформлении выберите адрес из подсказки, чтобы сохранить точку. Ручной адрес допустим, но без координат маршрут не строится. Если в поставке несколько складов, можно переключать участки. Оптимальный объезд складов не рассчитывается; схема не предназначена для навигации. Подключение 2ГИС и DaData предусмотрено, но с действующими ключами не проверено. [Настройка сервисов](docs/DEPLOY.md).

## Демонстрационные учётные записи

Для всех записей пароль `Demo2026!`.

| Роль | Логин |
| --- | --- |
| Покупатель | `buyer@example.test` |
| Поставщик | `supplier@example.test` |
| Второй поставщик | `supplier2@example.test` |
| Диспетчер | `dispatcher@example.test` |
| Водитель | `driver@example.test` |
| Администратор | `admin@example.test` |

Начать удобно с покупателя: открыть каталог, добавить предложения в корзину, выбрать адрес и оформить заказ. После учебного подтверждения оплаты можно войти как диспетчер и водитель, чтобы пройти поставку до завершения.

## Состав проекта

- `web/` — Next.js, React и TypeScript; адаптивный интерфейс калькуляторов и закупки.
- `api/` — NestJS API, OpenAPI, миграции и загрузка демоданных.
- `docs/` — руководство, архитектура, расчёты и результаты проверки.

Фотографии категорий взяты из Wikimedia Commons; авторы и условия использования перечислены в [списке изображений](docs/IMAGE_CREDITS.md). Фото в карточке показывает тип материала, а не конкретную позицию на складе.

Хранение данных — PostgreSQL. Денежные суммы передаются в копейках и фиксируются в заказе. При оформлении остатки проверяются и резервируются внутри транзакции; повтор запроса с тем же ключом не создаёт второй заказ.
